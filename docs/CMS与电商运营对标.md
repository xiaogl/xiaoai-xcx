# CMS 与电商运营对标

本次选取四个开源项目，分别考察内容创作、发布、目录建模和商品履约。选型依据是各项目覆盖的运营职责，没有按星标数做排名。

| 产品与官方资料 | 运营如何使用 | 对晓艾的设计影响 |
| --- | --- | --- |
| [WordPress 区块编辑](https://wordpress.org/documentation/article/work-with-blocks/)与[修订历史](https://wordpress.org/documentation/article/revisions/) | 运营可在正文内选择或配置内容块，并可对照历史版本 | 文章、笔记、商详共用一个编辑器。当前覆盖文字格式、标题、列表和引用。支持保留一份待发布修改，完整修订历史仍待建设 |
| [Payload 富文本字段](https://payloadcms.com/docs/rich-text/overview)与[草稿](https://payloadcms.com/docs/versions/drafts) | 字段承载结构化内容，同一条记录允许编辑草稿并保留已发布版本 | 正文存为 Quill Delta，并保留纯文本供检索和旧内容使用。文章和笔记区分保存草稿、发布与撤下，用户目录接口仅提供发布快照 |
| [WooCommerce 分类、标签与属性](https://woocommerce.com/document/managing-product-taxonomies/) | 分类组织商城导航，同一标签能描述多个商品，属性用来描述规格、组成变体 | 商品有两级分类，可多选标签。一级分类和标签使用稳定 ID。二级分类隶属一级分类，通过名称绑定，有引用时限制变更。规格组合独立维护价格和库存 |
| [Medusa 商品分类](https://docs.medusajs.com/user-guide/products/categories)与[库存预留](https://docs.medusajs.com/user-guide/inventory/reservations) | 分类具备层级、顺序与可见性。预留记录说明哪些库存已分配给订单，履约会处理该分配 | 晓艾支持分类启停、排序及关联保护。现有演示交易按 SKU 调整数量，有单独的订单状态。多库位预留和退货验收入库仍待建设 |

## 运营验收路径

1. 在内容管理新建标签。打开养生文章或社区笔记，填写标题、作者、正文，选择分类和标签。
2. 保存草稿，再从另一个浏览器进入同一演示空间。首次发布前用户端不可见。发布后检查详情中的排版和标签。
3. 修改已发布稿件并保存草稿。用户端应继续读到上一版。再次发布后刷新，正文和标题一起更新。撤下后旧链接应显示内容暂未发布。
4. 在电商管理创建商品分类和标签，给商品选分类、标签和规格。用户从分类目录筛选商品或点击详情标签搜索。标签改名后查看关联商品，停用后检查展示，删除前检查引用提示。
5. 结算时修改收货信息，记录订单号。后台核对收件人和地址，再发货或处理仅退款。未发货退款回补原 SKU，发货后的仅退款不增加库存。

## 仍影响运营的差距

| 场景 | 现状与影响 |
| --- | --- |
| 图文素材与多人协作 | 本机选择的封面依赖当前浏览器的素材存储。跨设备素材库、正文插图、历史版本对比恢复、定时发布和审核分工仍需建设 |
| 分类与批量编目 | 商品支持两级分类，内容分类为单层。商品二级分类有引用时须先处理关联。尚无批量迁移商品和任意层级分类树 |
| 实物售后 | 有演示付款、物流登记和仅退款审核。退货物流、收货检验、部分退货与按检验结果入库尚无完整流程 |
| 课程与渠道 | 课程发布进入共享目录，购课权益仍依赖用户本机记录。加盟商、经销商申请及推广员提现尚未形成服务端审核与结算流水 |
| 缺货运营 | 商品缺货时显示到货提醒。订阅登记、补货后通知及送达记录尚未接通 |
