# 2026-11-19 工作日志

## 项目结构
- `xiaoai-xcx` 是一个纯静态交互原型（小程序风格），无构建脚本。`package.json` 只有 `@vercel/blob` 依赖，没有 `dev` 脚本。
- 预览方式（重要）：必须 `node scripts/local-preview.mjs`，监听 127.0.0.1:4173。它同时提供静态页面和 `/api/operations` 数据接口。不要双击 index.html（file:// 下接口请求失败，报"业务目录暂时无法加载"），也不要用 python http.server（无 API）。服务是会话级后台进程，会话结束会停；重启服务才能加载后端模块改动。
- 主要源码：`index.html`（入口，script/link 带 `?v=` 版本号做缓存控制）、`js/pages-feed.js`（视频 feed + 社区浏览 + 搜索 + 笔记发布）、`css/app.css`、`js/core.js`（`XA` 全局、`XA.art`/`ui.cover`、`importMedia`/`mediaPreview`）。
- 图片素材走 `XA.importMedia(file, kind)` 存入 IndexedDB，记录只存 media 引用 `{key,kind,...}`，渲染用 `XA.mediaPreview(ref)`；`ui.cover(record, cls)` 有 `record.coverMedia` 就渲染真实图片，否则用 `art` 插画。
